# Mahir Akash — Portfolio

A responsive one-page portfolio built with React, Vinext, and the OpenAI Sites runtime.

## Customize

Edit `app/page.tsx` to replace the sample project descriptions and the placeholder contact email (`hello@example.com`) with your real information. Global styling lives in `app/globals.css`; page metadata lives in `app/layout.tsx`.

## Run locally

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```
